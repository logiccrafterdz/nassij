استلام المخرجات
01 // LAYER OF INTELLIGENCE

طبقات الفهم البصري

تحديد عمق التحليل المطلوب قبل بدء المعالجة.

الاستخراج الهجين

يجمع بين النص الرقمي الأصلي ومعالجة الـ OCR للصور، وهو الأفضل والأسرع لمعظم الملفات.

فهم التخطيط العميق

يفكك الهيكل المعماري للصفحة: يتتبع الأعمدة والجداول المدمجة لإعادة البناء بدقة مطلقة.

التجريد السريع

قراءة نصية فورية. مثالي للكتب والروايات حيث يهم النص المتدفق أكثر من الهيكل المكتبي.

02 // TYPOGRAPHIC SOUL

هوية الحرف

المخرجات الرقمية يجب أن تعكس شخصية النص. اختر النسق الطباعي للوثيقة النهائية.

النسق الهندسي الواضح

حداثة، تقارير، شاشات (IBM Plex)

النسق الوثائقي التراثي

أبحاث، كتب، وثائق رسمية (Amiri)

النسق الطباعي المعاصر

مجلات، نشر حديث (Cairo)

LIVE PREVIEW

اللغة العربية لغة حيّة، قابلة للامتداد والتشكل. نسيج يحترم هذا البناء ويعيد صياغته رقمياً بدقة متناهية.

04 // BEYOND THE UI

المحرك المفتوح

الواجهة مجرد قشرة. خلفها يقبع محرك "نسيج" البرمجي، متوفر كمكتبة Python قوية وـ CLI لتتكامل مع أنظمتك المعقدة.

LINUX MACOS WINDOWS
BASH 
# تثبيت المحرك محلياً
pip install nassij

# ترجمة المخطوطة إلى وثيقة ذكية
nassij convert thesis.pdf -o thesis.docx \
  --mode accurate \
  --font "Tajawal"
